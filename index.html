Towards Kinematic Actionable Infeasibility Detection in Motion Planning

Aayush Rath, Lakshya Jindal, Antony Thomas

IEEE Robotics and Automation Letters (RA-L) 2026

PDF ↗ Code ↗

Abstract

Motion planning in robotics requires not only computing collision-free paths, but also certifying infeasibility when no such path exists. While complete methods are limited to low-dimensional spaces, sampling-based planners cannot generally provide finite-time infeasibility certificates.

We present a geometry-driven framework for certifying infeasibility through an explicit, resolution-dependent analysis of configuration-space topology. Using signed distance fields, our approach traces separating manifolds induced by obstacle boundaries directly in configuration space, enabling both the detection of infeasibility and identification of its geometric causes.

To address computational challenges, we develop a GPU-accelerated parallel frontier-expansion algorithm for efficient simplicial reconstruction in high-dimensional spaces. Experiments on 4-DOF and 5-DOF robot scenarios demonstrate the feasibility of computing such certificates, with further opportunities for improving scalability to higher-dimensional settings.

Method Overview

The method traces obstacle-induced separating manifolds in configuration space, then identifies the geometric structures responsible for separating start and goal configurations.

Key Contributions

Geometric Infeasibility Certificates

Trace separating manifolds in configuration space to certify when a collision-free motion cannot connect the specified configurations.

Actionable Geometric Explanations

Identify the geometric structures responsible for infeasibility rather than simply reporting planning failure.

GPU-Accelerated Frontier Expansion

Exploit parallel computation for efficient simplicial reconstruction of obstacle-induced boundaries in configuration space.

Evaluation in Higher-Dimensional Spaces

Evaluate infeasibility certification on 4-DOF and 5-DOF robotic motion-planning problems.
